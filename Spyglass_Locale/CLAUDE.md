# Spyglass_Locale (locale companion)

Owns every **non-English name table** (items, instances, bosses, professions, trade skill
categories and tools): the generated ones, and on a non-English client the item names it learns
in-game (`SpyglassLocaleDB`). Depends on `Spyglass` (`## Dependencies: Spyglass`) and
talks to it only through the public API (`Data.names`, `Data:GetItemIDs`, `Data:AddNames`,
`RegisterCommand`, `Log`/`LogAt`). It is load-on-demand; the core asks the client to load it at
startup outside the English locales (`enUS` and `enGB`).

Where each name comes from, how the core resolves names, the in-game lookup and adding a locale:
**`docs/localization.md`** — read it before changing this addon.

## Files (`Spyglass_Locale.toc`, in load order)

- `Spyglass_Locale.lua` — the bootstrap. Declares the private-table class `SpyglassLocale`
  (its `---@field`s are here; there is no `types.lua`), stores `name`, `api` = `Spyglass`,
  `coreAPIVersion`, and `log`, a tiny logger whose `chat` / `info` / `debug` forward to
  `Spyglass.Log` / `Spyglass.LogAt`, so output shares the core's prefix and level setting.
- `db/generated/` — **generated by `npm run gen`, never hand-edited.** `locales/<locale>/`
  `items.lua`, `instances.lua`, `bosses.lua` and `crafting.lua`. There is no loader XML: the TOC
  lists the four files as `db\generated\locales\[TextLocale]\<file>.lua`, so the client reads only
  its own language, and every client language (`enUS` and `enGB` included) must have all four
  files, as placeholders where there are no names — a missing one is a `LUA_WARNING` at login,
  and `check:addons` enforces it. Excluded from LuaLS and StyLua.
- `src/db.lua` — `app.dbDefaults` for AceDB,
  `global.locales[locale] = { build?, items = { [itemID] = name }, missing = { [itemID] = true } }`
  (a `["*"]` default, one entry per client language), and the `SpyglassLocale.DB` types.
- `src/ace.lua` — `app.addon`, the AceAddon object. `OnInitialize` opens `SpyglassLocaleDB`;
  `OnEnable` registers `/sg locale [rescan]` through `Spyglass:RegisterCommand`, `OnDisable`
  unregisters it.
- `src/itemnames.lua` — `app.itemNames`, the Ace module that learns the item names the generated
  files lack, a few per tick and never in combat. English clients (`GetLocale() == "enUS"`) keep
  no state and run nothing.
