## Installation

Download from [curseforge](https://www.curseforge.com/wow/addons/spyglass-loot/), [wago.io](https://addons.wago.io/addons/spyglass) or directly from the GitHub releases, and put it into `..\World of Warcraft\_classic_beta_\Interface\AddOns`
