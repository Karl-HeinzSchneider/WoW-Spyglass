# Modern loot and collection browser for World of Warcraft Forever.  

## Features

- Blizzardlike UI with focus on UX (right click = back, multiple tabs saved throughout sessions etc)
- Extensive collections for Dungeons, Raids, Crafting, …
- All dungeon quests with notable pre and follow-up quests
- Locations and NPCs with clickable button to create shareable map pin
- Searchable item database
- Smart filter by class with greyout/hide
- List (e.g. Favorites) with import/export function
- Designed with love in Germany
