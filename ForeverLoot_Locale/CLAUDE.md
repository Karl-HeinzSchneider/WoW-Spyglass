# ForeverLoot_Locale (locale companion)

Owns every **non-English generated name table** (items, instances, bosses) and, once a UI-string
registry exists in the core, translated UI strings. It has no SavedVariables and no logic of its
own. Depends on `ForeverLoot` (`## Dependencies: ForeverLoot`) and talks to it only through the
public API: `ForeverLoot.Data:AddNames(locale, kind, table)`. Rules for all addons are in the
root `CLAUDE.md`; the ownership contract is `docs/architecture.md`.

## Files

- `ForeverLoot_Locale.toc` — `ForeverLoot_Locale.lua`, then `db\generated\generated.xml`.
- `ForeverLoot_Locale.lua` — the bootstrap. Declares the private-table class `ForeverLootLocale`
  (`name`, `api` = `ForeverLoot`, `coreAPIVersion`). Nothing else lives here yet; if code is
  added, keep it to the public API.
- `db/generated/` — **generated by `npm run gen`, never hand-edited.** `generated.xml` lists
  `locales/<locale>/instances.lua` and `bosses.lua` for every non-English locale in
  `.contribute/data/config.json` (`locales`) and `locales/<locale>/items.lua` for every
  non-English locale that has been scanned in-game. Each file starts with
  `if GetLocale() ~= "<locale>" then return end`, so shipping every locale costs other clients
  nothing. Excluded from LuaLS and StyLua.

## How names flow

The core keeps the generated `enUS` tables as its standalone fallback
(`ForeverLoot/db/generated/locales/enUS/`); the generator (`src/generate.ts`, `build()`) routes
every other locale here. Item names come from in-game scans on a client of that language
(a deDE scan adds German names next to the English ones in `.contribute/data/items/*.json`);
instance and boss names come from wago.tools for the configured locales. The core resolves a
name as client locale → enUS → `C_Item.GetItemInfo` → `"Item #id"`, and `AddNames` fires
`OnDataChanged`, so late registration refreshes open views.

## Adding a locale

Add it to `locales` in `.contribute/data/config.json` (instance/boss names) and/or scan items on a
client of that language and `npm run import`, then `npm run gen`. Nothing in this directory is
edited by hand.
